# ADR-0001：進階油畫 NPR 的筆刷尺度校準

- 狀態：採用中，補記既有實作
- 記錄日期：2026-10-06
- 選值與實作：Codex
- 範圍：`NPR_Paint_Advanced()` 的筆刷半徑與 `58.0` 比例常數

## 背景

進階油畫由大到小畫三層筆觸。若所有圖片都使用固定像素半徑，同一筆刷在小圖上佔的比例較大，在大圖上佔的比例較小。希望使用者沿用相同倍率時，不同尺寸圖片有近似的相對筆觸尺度。

原始實作直接寫入 `58.0`，缺少對選值理由的說明。本紀錄補上其設計意圖與限制。它是既有實作的事後紀錄；目前沒有參數搜尋或跨多張圖片的量化比較紀錄，因此無法主張 58 是最佳數值。

## 決策

以影像短邊作為尺寸基準，將作業範例 `wiz.tga` 的三層筆刷校準為 **8、4、2 像素半徑**，並提供 `brushScale` 調整整體粗細。

`wiz.tga` 的尺寸為 593×464，短邊為 464。先選定最大半徑 8，再反算比例：

```text
比例除數 = 參考圖片短邊 / 參考最大半徑
         = 464 / 8
         = 58

未限制的最大半徑 = 圖片短邊 × brushScale / 58
                 = 8 × (圖片短邊 / 464) × brushScale
```

實際程式再套用上下限：

```text
R = clamp(min(width, height) × brushScale / 58, 2, 32)
radii = [R, max(1, R/2), max(0.75, R/4)]
```

- `brushScale` 預設為 1，接受 0.5～3。
- 最大筆刷半徑限制在 2～32 像素，避免極端尺寸產生過小或過大的筆刷。
- 中、小筆刷另有 1 與 0.75 像素的下限，避免細層筆觸持續縮小。
- 基本 NPR 仍使用原本的 7、3、1；本紀錄只解釋進階油畫的參數。

## 為什麼選這個方案

**8、4、2 是風格預設。** 大筆概括色塊，之後以半徑逐次減半的筆刷補細節；8 是針對範例圖選的起始粗細。這個選擇沒有唯一正確值，58 也不是作業或論文規定的常數。

**選短邊作為基準。** 使用長邊時，狹長圖片可能因長邊很大而得到相對短邊過粗的筆刷。短邊基準較容易控制筆刷相對於圖片較窄方向的比例。

**提供單一倍率。** 使用者可調整 `brushScale` 取得較細或較粗的筆觸，無需先理解三層半徑之間的關係。

## 替代方案

下表是補記時整理的取捨，未對所有方案進行實測比較。

| 方案 | 優點 | 取捨 |
| --- | --- | --- |
| 固定半徑 8、4、2 | 規則簡單，同一像素尺度容易比較 | 圖片尺寸改變時，相對筆觸大小不同 |
| 按長邊或對角線縮放 | 同樣能隨解析度調整 | 狹長圖片可能使用相對短邊過粗的筆刷 |
| 按局部紋理調整半徑 | 可針對不同內容選擇粗細 | 需要額外的尺度估計與驗證；目前先以色差決定細層補畫位置 |
| 採用其他比例除數 | 可形成不同粗細預設 | 必須重新確認示範圖與使用者預期；58 尚未證明優於其他合理值 |

## 影響與限制

在上下限尚未生效時，圖片尺寸放大一倍，三層半徑也會按比例放大。達到任一上下限後，這種比例關係便會改變。

倍率為 1 的例子：

| 圖片短邊 | 三層半徑 | 說明 |
| --- | --- | --- |
| 58 | 2、1、0.75 | 下限生效 |
| 464 | 8、4、2 | 範例圖校準值 |
| 928 | 16、8、4 | 按尺寸放大 |
| 3712 | 32、16、8 | 最大半徑上限生效 |

筆刷半徑還會影響參考圖模糊程度、網格間距和每次追蹤的步長，因此修改這個比例會一起改變筆觸分布及細節表現。較大筆刷雖然通常減少候選網格數，但每筆的繪製範圍也會增加，不能只憑半徑判斷總執行時間。

目前以 `wiz.tga` 為校準範例。不同題材、長寬比及細節密度仍可能需要調整倍率；此決策不保證不同解析度的結果逐像素一致。

## 驗證與後續變更

本次補記核對了現行公式及範例尺寸，只新增文件、連結和程式註解，保留原本運算式。沒有因文件變更重新執行影像演算法測試。

若未來改動比例或上下限，應使用相同來源圖片、相同種子，比較數種解析度與不同題材的成果，同時檢查細節、相對筆觸尺度及執行時間，再新增決策紀錄說明取代理由。
