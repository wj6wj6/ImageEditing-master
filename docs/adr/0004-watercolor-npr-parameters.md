# ADR-0004：水彩 NPR 的常數來源與選值依據

- 狀態：採用中，補記既有實作
- 記錄日期：2026-10-06
- 風格預設的選值者：Codex
- 範圍：`NPR_Watercolor()`、`WaterPigment()`、`DrawWatercolorStroke()`、紙色與紋理輔助函式
- 對應原始碼：[TargaImage.cpp](../../src/TargaImage.cpp)、[預設參數](../../src/TargaImage.h)

## 背景與決策

水彩流程包含程序紋理、三層濕畫、顏料密度內插、紙面調制與 RGB 乾筆。多個數字只有運算式，缺少單位、來源與選值限制，因此補記如下，並加入就地註解。

**這是一組由我指定的外觀近似參數。沒有保留系統性比較，能證明 60、0.84、0.018 或其他風格值優於相鄰值。** 本紀錄可解釋目前數值在程式中的角色和範圍；不把事後的代數展開當成原始調參紀錄。視覺參考也沒有提供這些精確參數。

保留現行運算式，將數字區分為公式／格式、抽樣近似、數值保護和風格預設。此流程沒有求解水流或顏料散射；以下的「濕度」是 0～1 的程序紋理，「密度」是每通道的對數色彩表示，均不是實測物理量。

## 1. 尺度、三層選點與密度底色

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| `brushScale = 1`，允許 `0.5～3` | 風格／倍率 | 1 為基準，半倍至三倍是我指定的介面範圍；增加倍率會一起影響筆刷、參考圖模糊及追蹤步長 |
| `base = clamp(shortSide*brushScale/60, 2, 24)` | 風格／像素 | 選定短邊的 1/60 作為基準，限制在 2～24。**沒有留下將 60 從某個目標半徑反推的紀錄**，它是獨立於油畫 58 的預設。上下限生效時不再等比例縮放 |
| 三層半徑 `{2*base, base, max(0.8, 0.35*base)}` | 風格／像素 | 先鋪大色塊，再補中、小尺度。2、0.35 和細層下限 0.8 由我指定；最粗層最大半徑是 **48**，因為 base 的 24 還要乘 2 |
| 層數 `3`、索引 `0、1、2` | 流程結構 | 對應三組半徑與門檻；增加層數時須同步調整陣列及細節圖的來源層 |
| 補畫門檻 `{0,18,12}` | 風格／RGB 歐氏距離 | 中層 18、細層 12，讓細層更容易補畫；精確值是預設。第一個 0 為占位，粗層以 `layer == 0` 繞過閾值檢查 |
| 初始密度 `pigment * 0.85` | 風格／密度倍率 | 密度先減為 85%，使初始底色更接近紙色。**不是 85% RGB 不透明度**；此處還原色彩使用 `paper*exp(-0.85*D)` |
| `grid = max(2, round(radius*1.25))` | 風格＋取樣／像素 | 網格約為半徑的 1.25 倍，至少 2 像素，讓寬濕筆的種子較疏；2 和 1.25 都是選定值。減小格距通常會增加候選筆觸 |
| 累計初值 `0`、最佳候選初值 `-1` | 程式結構 | 有效候選為非負濕度或誤差，-1 保證第一個有效候選可被選上。第一層偏好濕度大的點，其他層偏好誤差大的點 |
| 濕畫不透明度 `0.50、0.42` | 風格／密度內插權重 | 第一層 0.50，後兩層 0.42；還要乘柔邊覆蓋與顆粒權重。兩者覆寫共用追蹤函式的 0.86，控制 D 空間的替換程度 |
| `seed = 1337` | 可重現性 | 任選的固定預設，讓同一執行檔、輸入和參數可重現；數字本身沒有畫質必要性 |

以短邊 464、倍率 1 作為**公式例子**：base 約 7.733，三層半徑約 15.467、7.733、2.707。這是代入目前公式的結果，不是 60 的歷史選值證據。

## 2. 濕度與紙張顆粒

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| 濕度混合權重 `0.65、0.35` | 風格／權重 | 65% 較大尺度與 35% 較小尺度的平滑噪聲，總和為 1，濕度維持在 0～1；提高小尺度比重會增加細碎變化 |
| 濕度取樣除數 `base*2.3、base*0.65` | 風格／噪聲格點間距 | 決定兩個紋理場的空間尺度；除數較大，起伏較寬。此處的 0.65 是尺度，與上一列 0.65 權重不同；沒有精確尺度的比較證據 |
| 顆粒混合權重 `0.6、0.4` | 風格／權重 | 60% 每像素噪聲、40% 平滑噪聲，形成細顆粒與較連續的紋理，範圍維持在 0～1 |
| 顆粒平滑噪聲除數 `2.8` | 風格／像素 | 格點間距為 2.8 像素；此處不乘 base，所以顆粒尺度不隨圖片尺寸等比增加。調大使起伏更寬 |
| 種子 XOR `0x9e3779b9u、0x85ebca6bu、0xc2b2ae35u` | 工程預設／位元混合 | 讓幾個紋理場使用不同的種子輸入。精確選值來源未記錄，也沒有統計驗證顯示產生的紋理彼此獨立 |
| 雜湊乘數 `374761393u、668265263u、1274126177u` 與右移 `13、16` | 工程預設 | 與油畫使用同一組座標混合方式，精確來源及統計品質未驗證；詳見 [ADR-0002](0002-advanced-npr-parameter-provenance.md) |
| `hash & 65535u`、除以 `65535.0` | 資料轉換 | 取低 16 位，將 0～65535 映成 0～1。油畫取低 8 位，此處的 65535 是位元範圍，不是顆粒強度 |
| 四個格點、`+1`、`1-t` 與 `t` | 插值結構 | 取相鄰四個噪聲值，在兩軸以權重和為 1 的方式內插，維持 0～1 範圍 |
| `SmoothPaintStep(0,1,t)` 的 `3、2` | 公式 | 使用 `3t²-2t³` 讓格點間的過渡在端部變平；係數推導見 [ADR-0003](0003-cartoon-npr-parameters.md) |

以上紋理值由固定座標與種子生成，沒有模擬水量隨時間流動。加權結果落在 0～1，是由各輸入範圍與正規化權重推得，並不代表具有特定機率分布。

## 3. 紙色、冷色暗部與對數密度

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| 紙色 `{244,237,219}` | 風格／RGB byte 值 | 我選的暖紙底，後續密度轉換和還原都以它為基準；改色會影響整個水彩流程 |
| 暗部門檻 `0.10、0.65` | 風格／正規化亮度 | 亮度不高於 0.10 時完整加冷色偏移，不低於 0.65 時不加；中間平滑過渡。兩端點未經系統比較 |
| 暗部偏移 `{-3,1,6}` | 風格／RGB byte 值 | 暗部減少紅色、增加少量綠與藍，形成冷色。是加法偏移，沒有物理顏料配方來源 |
| 原色／紙色權重 `0.86、0.14` | 風格／比例 | 先混入 14% 暖紙色再加冷色偏移；提高紙色比例會更接近紙色。這個 0.86 與油畫的筆觸不透明度沒有參數關聯 |
| `D = -log(C / paper)`、`C = paper*exp(-D)` | 所採用的色彩表示 | 使用自然對數及其反函式，讓較暗的色彩對應較大的非負密度。濕畫層在此空間內插；不是完整顏料混合或水流模型 |
| 比值限制 `0.02～1.0` | 數值保護＋表現範圍 | 0.02 避免 log(0)，同時把這一步轉換的密度限制到約 3.912；精確下限是我選的。上限 1 使此轉換不產生負密度，轉回的通道不高於紙色。後面的紙面調制與乾筆另行處理 |

`WaterPigment()` 會先做紙色與暗部處理。繪製濕筆時，`DrawWatercolorStroke()` 對已取得並擾動的筆觸色直接做對數轉換，沒有再次混入 14% 紙色。兩處雖然同樣用 log，但前處理並不相同。

## 4. 筆形、柔邊與濕邊沉積

這裡的 `d` 是「到筆觸路徑的像素距離 ÷ 當地有效筆刷半徑」，屬於無單位的正規化距離。以下位置或寬度常數都應在這個尺度下理解。

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| 包圍範圍 `1.5*radius + 1` | 取樣範圍／像素 | 1.5 是我選的餘裕，1 像素包住離散邊界。目前最大濕度放大 1.2 倍、覆蓋截止 1.15 倍，乘積為 **1.38**，在 1.5 的範圍內；更改兩者須一起檢查包圍範圍 |
| 距離初值 `2.0` | 程式結構／正規化距離 | 尚未覆蓋的哨兵，大於截止 1.15；之後取所有線段距離的最小值。2 不是筆刷半徑或透明度 |
| 收尖 `0.75 + 0.25*sin(π*progress)` | 風格／半徑比例 | 中段接近完整半徑、兩端趨近 75%。0.25 補到 1；相較更尖的筆刷，這組值保留較寬的筆端，但精確比例未驗證最優 |
| 進度 `(i-0.5)/(path.size()-1)` | 幾何近似 | 以線段索引中點估計進度，未按實際弧長正規化；與油畫共用相同做法 |
| 退化線段 `length2 > 1e-8`，投影 `t∈[0,1]` | 數值保護＋幾何公式 | 極短線段使用端點，其他情況求到有限線段的最近點；epsilon 量級是工程預設 |
| 濕度寬度 `0.8 + wetness*0.4` | 風格／半徑倍率 | 濕度 0～1 對應 **0.8～1.2 倍**半徑，以濕度 0.5 為一倍。增加變動幅度會讓筆緣更不規則 |
| 覆蓋過渡 `0.55、1.15` | 風格／正規化距離 | d≤0.55 時完整覆蓋，d≥1.15 時為零，中間用平滑函式衰減；過渡寬度為 0.60。外層的 `d>=1.15` 略過條件必須與此一致 |
| 濕邊位置 `0.84` | 風格／正規化距離 | 沉積權重 `rim` 的高峰位於 d=0.84；讓顏料在接近筆緣處偏重。這是權重的高峰，最後顏色也受覆蓋、底色及其他筆觸影響 |
| 濕邊分母 `0.018` | 風格／正規化距離平方 | `rim=exp(-(d-0.84)²/0.018)`；若寫成 Gaussian 形式，**sigma=sqrt(0.018/2)≈0.0949**。增大分母會讓沉積帶變寬。這是可推算的效果，並非精確值的歷史選取理由；與油畫顆粒的 0.018 用途完全不同 |
| 顆粒覆蓋倍率 `0.78+0.22*granulation` | 風格／比例 | 範圍 0.78～1，再乘柔邊與筆觸不透明度，產生較淡或較實的區域 |
| 沉積 `0.88+0.20*granulation+0.30*rim` | 風格／密度倍率 | 基礎、顆粒、濕邊三部分；界限為 0.88～1.38，精確係數由我設定。三個係數不需要相加為 1，因為它們調整的是目標顏料密度 |
| `D_old*(1-amount)+D_stroke*deposit*amount` | 線性內插公式 | 將舊密度朝已調制的筆觸密度混合；amount 在現行設定下保持 0～1。這不是每筆直接把密度相加 |

單點複製、B-spline 的四控制點與四樣本、反射與邊界裁切等共用部分，已記於 ADR-0002。

## 5. 最後的紙面調制與輪廓加深

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| `layer == 2` | 流程選擇 | 用最細的第三層參考圖計算輪廓加深權重，以保留較小結構；這個 2 是層索引 |
| 輪廓過渡 `4.0、18.0` | 風格／亮度梯度長度 | 梯度不高於 4 時不加深，不低於 18 時完整加深；精確值是預設。此 18 與補畫色差 18 的單位和用途不同 |
| `0.93+0.14*granulation+0.16*(wetness-0.5)` | 風格／密度倍率 | 調制既有密度，界限為 **0.85～1.15**，兩個紋理值皆為 0.5 時倍率為 1。0.5 用於置中，其餘係數為風格預設 |
| 紙面 `0.985+0.03*granulation` | 風格／色彩倍率 | 乘數為 **0.985～1.015，即 ±1.5%**；0.03 是完整變動寬度。此項乘在還原色彩上，不是密度上 |
| 額外輪廓密度 `0.10*accents*(0.4+0.6*wetness)` | 風格／密度增量 | 最多增加 0.10 密度；完整輪廓時隨濕度增加 0.04～0.10。提高增量會讓輪廓更暗；不能直接解讀成 RGB 減少 10% |
| `paper*paperGrain*exp(-pigment)` | 表示還原 | 將調整後密度轉回色彩並加紙面紋理，最後限制通道不超過 255 |

## 6. 乾筆補細節

| 程式中的值 | 類別／單位 | 用途、依據與調整影響 |
| --- | --- | --- |
| 參考圖半徑 `max(0.8, base*0.22)` | 風格／像素 | 用較小尺度保留細節；這是傳給 `PaintReference()` 的半徑，實際 Gaussian sigma 仍由該函式換算。0.8 與 0.22 為預設 |
| `detailGrid=max(3,int(base*0.85))` | 風格＋取樣／像素 | 約 0.85 倍 base 的格距，至少 3；此處轉 int 會向下取整，沒有加 0.5。與初始密度的 0.85 是獨立參數 |
| 最低誤差 `16²` | 風格／RGB 平方距離 | 格內最佳像素必須嚴格大於此值才加乾筆；平方是因為 `PaintColorError()` 回傳平方距離，16 本身是我選的門檻 |
| `abs(gx)+abs(gy) < 2` | 風格／梯度 L1 大小 | 略過缺乏方向變化的區域，避免在平坦處補太多碎筆。這裡使用分量絕對值總和，與上一節的歐氏長度不同；2 是預設 |
| `bestX=bestY=-1` | 程式結構 | 表示尚未找到符合門檻的位置，只有找到後才畫筆觸 |
| 乾筆半徑 `max(0.75, base*0.23)` | 風格／像素 | 細筆寬度與圖片尺度連動；0.75 是下限、0.23 是比例，均為預設。與參考圖半徑分開設定 |
| 乾筆不透明度 `0.38` | 風格／RGB 內插權重 | 覆寫共用追蹤函式的 0.86，透過 `DrawPaintStroke()` 在 **RGB** 畫布加細筆；其刷毛與邊緣會再降低實際覆蓋。不是前面 D 空間的內插 |

三層濕畫與乾筆均使用共用追蹤函式，其方向、停止條件、顏色擾動，以及乾筆的刷毛紋理參數見 ADR-0002。水彩只覆寫相應筆觸的不透明度，沒有另設一組追蹤公式。

RGB 的 3 通道、RGBA 的 4 通道、Alpha 索引 3、255、最後的 `+0.5` 取整，以及保留原 Alpha 的方式，均沿用共用像素格式。這些數字與風格係數需依所在運算式區分。

## 替代方案、影響與驗證

- 將風格值集中成具名設定，可把濕畫、紙面和乾筆分組，避免看到相同數字就一起修改；本次先補文件及註解。
- 依不同圖片尺寸改變紙張顆粒尺度，或更換程序噪聲，是可比較的其他方案；會改變既有紋理與可重現輸出。
- 若要主張某個值較合適，需要固定圖片與種子，分組比較筆刷、濕邊、紙面與乾筆，記錄視覺結果與時間。若要物理模擬，則需另外設計水流及顏料模型，不能只替換這些係數。

本次只補文件與註解，核對程式差異、常數表、數值範圍和本機連結；不因文件變更重新編譯或執行影像測試。範圍檢查能確認數字的意義，不能證明外觀最佳。
