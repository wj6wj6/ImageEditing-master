# ADR-0002：進階油畫 NPR 的常數來源與選值依據

- 狀態：採用中，補記既有實作
- 記錄日期：2026-10-06
- 風格預設的選值者：Codex
- 範圍：`NPR_Paint_Advanced()` 與其參考圖、梯度、追蹤、曲線、繪製輔助函式
- 前置紀錄：[ADR-0001：筆刷尺度校準](0001-advanced-npr-brush-scale.md)

## 問題與決策

原始程式含有許多未充分說明的數字。只解釋 `58`，仍無法讓讀者判斷其他數字的來源、單位和可調整性。

本紀錄將常數分成四類，逐項說明角色與取捨：

1. **公式或資料格式**：由選用的數學公式、通道數或像素格式決定。
2. **抽樣與近似**：在計算量、離散解析度和近似精度間取捨。
3. **數值保護**：處理接近零的除法、退化線段和合法索引。
4. **風格預設**：由實作者指定外觀與處理範圍，沒有唯一正確值。

保留現有運算式作為目前示範版本的基準，補上就地註解與本表。**對風格參數，可以說明它的作用及增減方向；目前沒有系統性的參數搜尋、消融比較或使用者評分，能證明例如 28 優於 27，或 0.86 優於 0.85。** 下表的「理由」記錄設計意圖，不代表已完成最優化驗證。

卡通與水彩專用參數分別記於 [ADR-0003](0003-cartoon-npr-parameters.md) 與 [ADR-0004](0004-watercolor-npr-parameters.md)。`PaintReference()`、`TracePaintStroke()`、`PaintSpline()` 和 `DrawPaintStroke()` 也被水彩使用，`PaintGradient()` 也被卡通及水彩使用，日後改值時需要一起檢查受影響風格的成果。

## 1. 主函式：尺度、選點與底色

| 程式中的值 | 類別／單位 | 為什麼存在、目前值的依據 | 改動的影響 |
| --- | --- | --- | --- |
| `brushScale` 預設 `1.0` | 風格／倍率 | 1 表示使用基準尺度，沒有額外放大或縮小 | 倍率變大，筆觸、模糊範圍和追蹤步長一起變大 |
| 允許倍率 `0.5～3.0` | 風格／介面範圍 | 我設定的半倍至三倍調整範圍，用來限制過度極端的效果；端點沒有最佳性證據 | 放寬可提供更多效果，但要驗證時間與圖像品質 |
| 最大半徑上下限 `2、32` | 風格／像素 | 限制最粗層的筆刷尺度；數值是工程預設，不是防止除零的必要條件 | 上下限生效時，停止依圖片尺寸等比例縮放 |
| 除數 `58.0` | 風格／尺度基準 | 以範例短邊 464、最大半徑 8 校準，`464 / 8 = 58`；詳見 ADR-0001 | 未碰到下限時，除數增大使筆刷變細 |
| `3` 個半徑／`layer < 3` | 風格／層數 | 我選擇大、中、小三層，兼顧色塊與細節 | 增加層數須同步調整半徑與閾值陣列，通常增加處理量 |
| 半徑倍率 `0.5、0.25` | 風格／比例 | 每次減半形成幾何級數；基準圖得到 8、4、2 | 接近 1 時各層大小差異較小；更小則細層更細 |
| 細層半徑下限 `1.0、0.75` | 風格／像素 | 保留小圖的有效筆觸寬度；0.75 可透過覆蓋率繪製次像素邊緣 | 更小可能讓筆觸變弱或更細碎；沒有驗證這兩個值最優 |
| `thresholds = {0, 28, 20}` | 風格／RGB 色差 | 中層門檻 28、細層門檻 20，讓細層較容易補畫；精確數值是我選的預設。**第一個 0 只是占位，第一層由 `layer == 0` 強制選取有效網格，沒有使用該閾值判斷。** | 門檻降低會增加需要補畫的格子；提高則保留更多粗筆觸 |
| 紙底 `242、238、228` | 風格／8-bit RGB | 我選的暖白紙色，R 稍高、B 稍低 | 改變初始底色的色溫 |
| 底色混合 `0.96、0.04` | 風格／權重 | 96% 參考圖加 4% 暖紙底，輕微混入紙色；兩者和為 1 | 提高紙底比重會更接近紙色，也改變後續誤差選點；不是所有原色都會變亮 |
| `grid = max(1, int(radius + 0.5))` | 抽樣／像素 | 網格大小約一個半徑，選點密度隨筆刷改變；正數加 0.5 再取整近似四捨五入，至少 1 才能前進 | 格子更小會增加候選筆觸，格子更大可能漏掉局部細節 |
| 格子中心的 `(... - 1) * 0.5` | 公式／座標 | `right`、`bottom` 是不包含的上界，最後有效像素為上界減 1；兩端平均得到像素中心 | 屬於索引與中心計算，不是調色或風格係數 |
| `bestError = -1` 與 `sumAlpha == alpha` | 程式初始狀態 | -1 是初始哨兵。第一個可見像素透過 `sumAlpha == alpha` 設定候選，之後再比較誤差；粗層的中心距離分數可能是負數 | 不能只假設所有候選分數都大於 -1 |
| `seed = 1337`（標頭預設） | 可重現性／整數 | 固定種子讓同一執行檔、輸入和參數可重現；1337 本身沒有畫質上的必要性 | 換種子改變擾動、排列與紋理 |

這裡的 RGB 色差為 `sqrt(ΔR² + ΔG² + ΔB²)`，三通道使用 0～255 數值。門檻 28 不是「每個通道都可以差 28」。它也不是經感知色彩空間校準的色差單位。

## 2. 參考圖與梯度

| 位置／數值 | 類別 | 依據與改動影響 |
| --- | --- | --- |
| `PaintReference`: `sigma = max(0.5, radius * 0.5)` | 風格＋抽樣 | 半個筆刷半徑作為模糊標準差；最小 0.5 像素避免核過度集中。倍數是本實作的尺度預設，增大會抹去更多細節 |
| 截斷範圍 `ceil(3 * sigma)` | 抽樣近似 | 高斯核理論上無限長；三倍標準差保留主要權重，截斷後重新正規化。更大範圍計算更多尾端，更小範圍近似較粗 |
| 核長 `2 * extent + 1` | 索引結構 | 中心左右各取 `extent` 個位置，再加中心點，形成奇數長度的對稱核 |
| 高斯指數分母 `2 * sigma * sigma` | 公式 | 來自所採用的 Gaussian 公式 `exp(-x²/(2σ²))`；其中 2 是公式係數 |
| `rgba[3] > 1e-6` | 數值保護 | 避免以接近零的模糊 Alpha 還原顏色；此處的 Alpha 尺度為 0～255。epsilon 是保護門檻，不是水彩或油畫的風格參數 |
| 無 Alpha 支援時回填 `240.0` | 風格／備援色 | 沒有可還原的顏色時使用我選的淺灰。有效格會略過原圖全透明像素，但參考圖鄰域的梯度仍可能受備援色影響 |
| 亮度係數 `0.299、0.587、0.114` | 既有亮度公式 | 沿用專案 RGB 轉亮度的加權，總和為 1；這些不是新增的油畫色彩擾動係數 |
| Sobel 的 3×3 鄰域與 `1、2、1` 權重 | 公式／離散算子 | 使用一方向的差分搭配另一方向的加權平滑來估計亮度變化 |
| Sobel 結果 `/ 8` | 梯度尺度約定 | 線性亮度斜坡經未正規化的這個核會得到 8 倍斜率，除 8 後對應每像素的變化量；改此尺度須一起檢查追蹤的弱梯度門檻 |
| 雙線性插值中的 `1-tx、tx、1-ty、ty` | 公式 | 按距離在四個相鄰梯度向量之間內插，各軸權重和為 1；`+1` 是取相鄰像素 |

例如半徑 8 時，`sigma = 4`，截斷半徑為 12，得到 25 個一維核元素。這與基本濾波指令的二項式核是不同的實作。

## 3. 路徑追蹤與筆觸顏色

| 程式中的值 | 類別／單位 | 依據與增減效果 |
| --- | --- | --- |
| 不透明度 `0.86` | 風格／0～1 | 我選的偏實色筆觸，同時保留疊色；沒有證據顯示精確 0.86 比 0.85 更好。刷毛與邊緣覆蓋率還會降低實際混色權重 |
| 均勻亂數 `0～1`、相位 `2π` | 公式／機率、弧度 | 標準均勻亂數區間；乘一整圈讓刷毛正弦紋理起始相位改變 |
| 平坦區角度 `-0.65 + (u - 0.5) * 1.8` | 風格／弧度 | 以 -0.65 為偏斜方向，擾動約 ±0.9。這會使平坦區有偏好的筆勢，不是各方向等機率；-0.65 與 1.8 沒有最佳性證據 |
| `arms[2]`、兩個方向的正負號 | 追蹤結構 | 從種子沿同一切線往相反兩側延伸，將種子留在筆觸內部 |
| 每側最多 `7` 步 | 風格＋成本／步數 | 限制長筆觸範圍；每步約一個半徑，兩側最多共 14 次移動。更大可產生更長筆勢，也增加繪製範圍；7 是選定的預設 |
| 弱梯度門檻 `0.3` | 風格／亮度變化量每像素 | 梯度太小時方向容易被微小變化左右，改用上一方向或預設筆勢。此值依目前 Sobel 正規化尺度設定，沒有實測最佳性證據 |
| 方向混合 `0.65、0.35` | 風格／權重 | 65% 當地切線與 35% 上一步方向，混合後再正規化。提高前者會更貼著局部方向轉彎，提高後者會更直、更有慣性 |
| 向量長度 `1e-6` | 數值保護 | 接近零時停止，避免正規化時除以極小數；與 Alpha 使用的同數值 epsilon 是不同單位 |
| 座標 `+0.5` 再取整 | 抽樣 | 在合法、非負座標上選最近的像素來讀取顏色與 Alpha |
| 強色差門檻 `85²` | 風格／RGB 平方距離 | 起點固定筆觸色與前方參考色差太大就停止。85 是我選的上限；平方是因為比較函式回傳平方距離，不需要開根號 |
| `step >= 2` | 風格／步數 | 從第三次嘗試移動開始，才啟用「既有畫布更合適」的停止條件，容許短筆觸先形成；強色差與邊界條件始終有效 |
| 停止比較的下限 `20²` | 風格／RGB 平方距離 | 讓很小的色差不會過早終止追蹤。提高會容許較多色差；此 20 與主函式細層門檻 20 是獨立用途，不能因數值相同就視為同一參數 |
| 亮度擾動 `(u-0.5)*10` | 風格／通道數值 | 使整筆色彩共同變亮或變暗，幅度約 ±5；0.5 是把亂數置中，10 是我選的擾動總寬度 |
| 飽和度倍率 `1.04` | 風格／比例 | 將每個通道與亮度灰值的距離放大 4%，再加擾動；選擇輕微增色，沒有精確倍率的比較證據 |
| 通道擾動 `(u-0.5)*3` | 風格／通道數值 | 每通道再變動約 ±1.5，使相鄰筆觸不完全同色；增大更斑駁，減至 0 保留原始通道關係 |

## 4. 曲線取樣與筆刷繪製

| 程式中的值 | 類別 | 依據與增減效果 |
| --- | --- | --- |
| 三次 B-spline 每段 `4` 個控制點，基底中的 `1、3、4、6` 等 | 公式 | 所選均勻三次 B-spline 的多項式係數；四個基底權重的和為 1。這些須作為完整公式理解，不能單獨當風格滑桿改動 |
| 端點各額外重複 `2` 次 | 曲線邊界處理 | 連同原控制點，端部有三個相同位置，使目前曲線實作到達筆觸尖端 |
| 每段取 `4` 個樣本、`t = sample/4` | 抽樣近似 | 在 0、0.25、0.5、0.75 取樣，末尾再補終點；這是我選的計算量與曲線平滑度取捨。與四個控制點的 4 用途不同，若改密度須一起改迴圈與除數 |
| 線段進度 `(i-0.5)/(path.size()-1)` | 幾何近似 | 以取樣線段索引的中點估計整筆進度，決定粗細變化；未按實際弧長正規化 |
| 收尖 `0.65 + 0.35*sin(π*progress)` | 風格／比例 | 中間最厚、兩端趨近最大半徑的 65%；0.35 補到 1。這組權重與追蹤方向的 0.65／0.35 是不同決策 |
| 包圍盒額外 `1` 像素 | 抽樣邊界 | 包住筆刷柔邊並用整數範圍遍歷；座標會再裁到圖片內 |
| 單點複製成兩點、退化線段取 `t=0` | 幾何邊界處理 | 沒有足夠控制點形成路徑時，仍可畫出一個筆刷印記 |
| 投影參數限制 `0～1` | 公式 | 求到有限線段的最近點，避免延伸到線段兩端以外 |
| 長度平方門檻 `1e-8`、長度門檻 `1e-4` | 數值保護 | 兩者互為平方，避免退化線段的投影與方向計算除以零；單位分別為像素平方、像素 |
| 柔邊 `clamp(radius + 0.5 - distance, 0, 1)` | 抽樣近似 | 在半徑內外各約半像素形成一像素寬過渡；0.5 來自這個柔邊寬度選擇。它是距離式覆蓋近似，非精確像素面積積分 |
| 刷毛頻率 `2.2` | 風格／弧度每像素 | 橫向正弦週期約 `2π/2.2 ≈ 2.86` 像素，形成細刷毛；頻率更高會更密，也較容易出現取樣紋。2.2 沒有最佳性證據 |
| 覆蓋率調制 `0.90 + 0.10*sin(...)` | 風格／比例 | 刷毛調制範圍為 0.8～1，再乘基礎不透明度與邊緣覆蓋率 |
| 顏料明暗 `1 + 0.035*sin(...)` | 風格／比例 | 刷毛造成約 ±3.5% 的顏色強度變化；更大會更明顯，過大可能像條紋 |
| 混色中的 `1-coverage` 與 `coverage` | 公式 | 既有畫布與新筆觸的線性內插，權重和為 1；這不是把全圖 Alpha 改成筆刷不透明度 |

## 5. 紙面顆粒、像素格式與通用數字

| 程式中的值 | 類別 | 依據與限制 |
| --- | --- | --- |
| `374761393u、668265263u、1274126177u` 與位移 `13、16` | 工程預設／整數混合 | 用固定的無號整數乘法與 XOR 將座標、種子混成紋理值。這些值不代表影像物理量；目前沒有保留精確選值來源推導或統計品質驗證，不主張這組常數最佳，也不把它描述成完整的標準雜湊實作 |
| `hash & 255u`、再除以 `255.0` | 資料轉換 | 取低 8 位，將 0～255 映射到 0～1；與 RGB 上限同為 255，但此處是在轉換紋理數值 |
| 顆粒 `(noise-0.5)*0.018` | 風格／比例 | 0.5 將範圍置中；0.018 是我選的完整擾動寬度，因此乘數為 **0.991～1.009，即 ±0.9%** |
| RGB `3` 通道、RGBA `4` 通道、Alpha 索引 `3` | 資料格式 | 決定陣列長度與位移；不要把它與三層筆刷的層數 3 混為一談。`ValidImage()` 的 `INT_MAX/4` 也來自每像素 4 bytes，以限制既有整數索引範圍 |
| 顏色與 Alpha 的 `0、255`，Alpha 除以 `255` | 資料格式 | 8-bit 範圍，以及 0～255 轉成 0～1 的覆蓋比例 |
| 寫回前 `+0.5` | 量化近似 | 配合截斷取整，將非負計算結果近似四捨五入到 byte |
| `0、1` 初始化與 `width-1、height-1` | 程式結構 | 零起始索引、空覆蓋、完整比例、最後有效像素等；具體角色依運算式而定 |

`ClampByte()` 內的 `1e-9` 是沿用的取整微量修正，用來避免接近整數的浮點誤差；它也不是油畫風格參數。各 epsilon 的用途有明確理由，但其精確量級仍是實作選擇，沒有記錄顯示它們是唯一或最佳門檻。反射邊界取樣中的 `2*(length-1)` 則是反射週期，來自所選邊界索引規則。`c_pi` 是既有的 π 近似值，供整圈相位及半圈正弦收尖使用。

## 替代方案與後續

- **改成具名參數或設定結構**：可讓程式更易讀，並區分相同數字的不同用途；需要另做等價重構驗證。本次先補紀錄與就地註解。
- **採用論文的一組完整風格設定**：更容易與來源對照；但此實作還包含雙向追蹤、刷毛與紙底等自行加入的設計，不能只替換數字就宣稱完整重製。
- **做系統性的參數比較**：固定圖片、種子和其他參數，每次改一組，觀察細節、筆觸、邊界及耗時。必要時加入不同尺寸、題材、透明邊界和使用者評估，才有依據推薦特定數值。

本次只新增註解和文件。驗證以原始碼差異、常數表對照、數值範圍與本機連結為主；沒有因註解變更重新編譯或重跑影像測試。現有測試通過可支持程式行為與邊界處理，不能用來證明某組風格參數最好看。
