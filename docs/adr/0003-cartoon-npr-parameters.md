# ADR-0003：卡通 NPR 的常數來源與選值依據

- 狀態：採用中，補記既有實作
- 記錄日期：2026-10-06
- 風格預設的選值者：Codex
- 範圍：`NPR_Cartoon()`、`BilateralPaint()`、`CelPaintColor()` 與共用的 `SmoothPaintStep()`
- 對應原始碼：[TargaImage.cpp](../../src/TargaImage.cpp)、[預設參數](../../src/TargaImage.h)

## 背景與決策

目前流程為保邊平滑、HSV 色階簡化、輪廓描線。既有文件說明流程，但許多精確數值缺少來源與取捨。本紀錄補上用途、單位、選值依據和改動影響，並在原始碼附近加入註解。

下文區分「公式／資料格式」、「抽樣近似」、「數值保護」與「風格預設」。**風格預設是我為這個實作指定的值；沒有保留系統性的參數比較，能證明 40、36 或 1.12 優於相鄰值。** 現有影像及功能測試也不等於最佳參數的證據。下面對運算式的展開，是可核對的數學解讀；不是宣稱當時曾依這個過程調參。

使用者指定的遊戲外觀是視覺目標，這些常數沒有遊戲著色器參數的來源紀錄。現行版本為二維圖像處理，保留目前值作為可比較的基準。

## 1. 主函式的強度與保邊平滑

| 程式中的值 | 類別／單位 | 用途、選值依據與改動影響 |
| --- | --- | --- |
| `strength = 1.0`，允許 `0.5～3.0` | 風格／倍率 | 1 為基準，範圍由我指定。強度同時影響濾波半徑、明度階數、描邊閾值與加粗程度，不是單純放大某一個效果 |
| `radius = max(2, min(5, int(2 + strength)))` | 風格＋離散取樣／像素 | 半徑限制在 2～5；常數 2 是選定的起始偏移，正數轉 int 會向下取整。因此變化是階梯狀，沒有證據證明這個範圍最優 |
| `BilateralPaint(..., 3)` | 風格＋成本／次數 | 連續平滑三次，簡化色塊並盡量保留邊界。增加次數會增加計算，也可能消除細節；三次是我選的預設 |
| `size = 2 * radius + 1` | 索引結構 | 中心及左右各 radius 個位置；二維視窗為 `size × size` |
| 空間權重 `exp(-(x²+y²)/(2*radius²))` | 公式＋尺度選擇 | 分母的 2 來自 Gaussian 形式；**將標準差設為 radius，並在 x/y 各取 -radius～radius 的方形視窗**是本實作的選擇。增大半徑會納入更多鄰居 |
| 色差權重 `exp(-distance/(2*40²*3))` | 公式＋風格／RGB byte 值 | `distance` 是三通道平方差總和。此式等於 `exp(-(distance/3)/(2*40²))`，所以 40 對應每通道均方根色差的尺度。2 是 Gaussian 係數，3 是目前採用的通道平均尺度，**40 是未經系統比較的預設**。增大 40 會更容易混合不同顏色 |
| 查表長度 `3*255*255+1` | 資料格式＋近似 | 三通道最大平方距離為 195075，再加上索引 0，需 195076 格。以 `int(distance)` 查表會向下取整平方距離，是以整數分箱近似指數權重；最後索引裁到表內 |
| 全透明像素的 `0`、Alpha 權重 | 資料處理 | 無 Alpha 時暫存 RGB 歸零，該像素不參與有效顏色的加權；鄰居權重乘原始 Alpha。Alpha 的共同 255 倍尺度會在加權平均中抵消 |

例如三通道的色差均為 40 時，`distance = 3*40²`，色差權重約為 `exp(-0.5) = 0.607`，不是直接被排除。這說明目前值的效果，不能證明 40 是最佳設定。

目前的強度例子：

| strength | 濾波半徑 | 明度階數 |
| --- | --- | --- |
| 0.5 | 2 | 8 |
| 1.0 | 3 | 6 |
| 2.0 | 4 | 4 |
| 3.0 | 5 | 3 |

## 2. 色相、飽和度、明度與暗部色調

| 程式中的值 | 類別／單位 | 用途、選值依據與改動影響 |
| --- | --- | --- |
| RGB 除以 `255` | 資料格式 | 將通道從 0～255 轉成 0～1；不是風格強度 |
| `delta > 1e-6`、`maximum > 1e-6` | 數值保護／正規化通道值 | 接近灰色或黑色時避開不穩定除法，分別使用 hue=0 或 saturation=0；精確 epsilon 量級是工程選擇，沒有最佳性證據 |
| hue 的偏移 `2、4`、週期 `6`、區段界線 `1～5` | HSV 公式 | 以六個區段表示色相一整圈；這些是所用 RGB↔HSV 公式的結構，不是六種可選色彩 |
| `hueBins = 36` | 風格／色相格數 | 將整圈量化成 36 格，相鄰格相差 10 度。目的是適度簡化相近色相，精確格數由我指定；減少格數會更容易合併不同色相 |
| 飽和度倍率 `1.12` | 風格／比例 | 量化前提高飽和度 12%，讓色塊較鮮明，最後限制於 1；沒有記錄證明這個倍率最合適 |
| 飽和度 `*8`、`/8` | 風格＋量化／步距 | 選用 1/8 的間距，包含兩端共有 **9 個可能值**：0、1/8、…、1。這裡的 8 是間隔數；增大可提供更細的飽和度變化 |
| `bands = clamp(round(6/sqrt(strength)), 3, 8)` | 風格／明度階數 | 基準為 6 階，強度增加時以反平方根減少階數，限制在 3～8。6、上下限和反平方根關係皆為實作預設，形成較大的明暗色塊 |
| `bands - 1` | 量化公式 | N 個值包含 0、1 兩端時，有 N−1 個間隔，所以先乘再除 `bands-1` |
| 量化時的 `+0.5` | 取整近似 | 非負數先加半格再 floor，取最近的量化值；與強度下限 0.5 用途不同 |
| `chroma*(1-abs(fmod(hue,2)-1))` | HSV 公式 | 求色相區段內的第二個非零通道；2 的週期和兩個 1 屬於此三角函式形式 |
| 暗部過渡 `SmoothPaintStep(0.05, 0.6, value)` | 風格／量化後明度 | 明度不高於 0.05 時完整使用冷色偏移，不低於 0.6 時不加；中間平滑減弱。兩個端點由我指定，調高端點會把偏色延伸到較亮處 |
| 暗部偏移 `{3,5,11}` | 風格／RGB byte 值 | 藍通道加得較多，形成冷色暗部。這是加法偏色，原本純黑也會被提起；精確通道值沒有比較證據 |

飽和度的 9 個可能值、明度的階數和色相的 36 格，是三種不同設定；不代表最後整張圖片只有這幾種 RGB 顏色，因為後面還有暗部偏色與輪廓混色。

## 3. 梯度、輪廓與輸出

| 程式中的值 | 類別／單位 | 用途、選值依據與改動影響 |
| --- | --- | --- |
| 色彩差分係數 `0.275` | 風格／梯度尺度 | 可寫成 `0.55 * (相鄰兩側差/2)`，即一般中心差分的 55%。這只是代數解讀；沒有紀錄能推導為何精確選 0.275。提高它會使純色彩邊界更容易在與亮度梯度比較時勝出 |
| 取樣位置 `x±1、y±1` | 離散差分 | 比較兩側的相鄰像素；出界時採用既有反射邊界規則 |
| 梯度長度門檻 `1e-5` | 數值保護 | 梯度接近零時略過正規化與輪廓檢查。精確量級是保護門檻的實作選擇 |
| 正規化後 `round()` 方向 | 抽樣近似 | 將梯度方向轉成鄰近像素方向，用兩側大小進行非極大值抑制；不是連續方向的精確插值 |
| 輪廓閾值 `6/sqrt(strength)、22/sqrt(strength)` | 風格／目前梯度尺度 | 強度 1 時，6 以下無墨線、22 以上完整墨線，中間平滑過渡。提高強度會降低門檻，使較弱邊界也可描線；6、22 和強度關係沒有最佳性證據 |
| 加粗鄰域 `-1～1` | 抽樣＋風格／像素 | 以 3×3 鄰域擴張細線，僅向外取一圈像素；目前厚度以像素衡量，未按圖尺寸縮放 |
| 加粗權重：對角 `0.35`、其餘 `0.65` | 風格／比例 | 用較弱的對角權重抑制方塊感。中心原值已保存在 edge；鄰域候選透過 max 合併，**不是相加或加權平均**。這兩個值不必相加為 1 |
| 加粗倍率 `min(1.3, sqrt(strength))` | 風格／倍率 | 強度增加時增強鄰居線條影響，最高 1.3 倍。最大軸向候選權重為 0.845、對角為 0.455；這個上限是預設，沒有證據證明 1.3 最好 |
| 墨色 `{9,10,18}` | 風格／RGB byte 值 | 我選的深藍黑，避免全用純黑；精確色碼沒有來自遊戲的依據 |
| `1-edge` 與 `edge` | 線性內插公式 | 色塊與墨色的混合權重。目前參數使 edge 保持在 0～1，最後乘回原始 Alpha |
| `+0.5`、RGB `3`、RGBA `4`、Alpha 索引 `3` | 資料格式與量化 | 寫回時的四捨五入近似、通道數及位置；沿用 [ADR-0002](0002-advanced-npr-parameter-provenance.md) 的說明 |

亮度 Sobel、亮度係數、反射邊界和 `ClampByte()` 是共用函式，來源已記於 ADR-0002。調整色彩梯度係數時也要檢查輪廓閾值，兩者共同決定描線強弱。

## 4. 共用的平滑過渡公式

`SmoothPaintStep(low, high, value)` 先將位置轉成 `t = clamp((value-low)/(high-low), 0, 1)`，再算 `f(t) = 3t² - 2t³`。現行呼叫均使用 `high > low`。

這裡的 **3 與 2 是公式係數**：要求 `f(0)=0`、`f(1)=1`，而且兩端斜率皆為 0，令 `f(t)=a*t³+b*t²`，就得到 `a+b=1`、`3a+2b=0`，所以 `a=-2、b=3`。選用這種三次過渡是實作選擇；一旦選定這些邊界條件，係數便能推導。各呼叫給它的 low/high 則是各自的風格門檻。

## 替代方案、影響與驗證

- 將風格參數集中成具名設定，可區分多個相同數字的不同用途；目前先補文件及註解，另行重構時須驗證行為等價。
- 改用依解析度調整的濾波與線寬，可改變不同尺寸圖片的相對輪廓粗細；這會更動現有輸出，需要另做比較。
- 固定輸入，分組比較濾波、色階和描邊，才能為精確值建立可追溯證據。邊界、暗部、低飽和區與不同尺寸都需要檢查。

本次只補文件與註解，核對程式差異、公式、數值範圍及文件連結，不因文件變更重跑影像測試。任何「用途合理」的說明，都不等於「該精確值最佳」的實驗結論。
